# Historical code: 2026-05

이 폴더는 2026년 5월 연구 폴더에서 확인된 초기 PDB 구조 탐색·파싱·품질통계 코드를 보존한다.
파일 내용은 공개 저장소 정리 과정에서 수정하지 않았다.

## 구분

- `week1-core/`: 최초 구조 수집과 screening
- `week1-expanded/`: 후보군을 확장한 수집과 screening의 버전 발전
- `week2-analysis/`: mmCIF/NDB geometry 파싱과 초기 품질통계·그림

이 코드는 질문과 방법의 발전을 입증하는 역사적 자료다. 현재의 signed-six 결론, 방향 감사,
stretch 민감도와 전체 재현성 검증은 루트 `run_analysis.py`와 현재 `scripts/`를 사용한다.

원본별 SHA-256은 `../../CODE_HISTORY.md`에 기록했다.
